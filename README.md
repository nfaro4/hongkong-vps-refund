## 六、三种BGP宽带到底差在哪？买之前必须搞清楚

野草云的香港云服务器套餐里反复出现"普通BGP"、"优质BGP"、"精品BGP"、"国际BGP"几个词，第一次看绝对会懵。我去翻了一下官方FAQ的原文解释，结合自己实测，给你翻译成大白话：

- **普通BGP**：接入 HGC、WTT、NTT、Level3、Cogent、HE、HKIX、CMI 等多线，回程不针对中国内地专门优化。**适合做外贸站、海外业务、对国内访问速度不敏感的项目**。延迟最低，但国内晚高峰可能略有抖动。
- **优质BGP**：中国电信回程走 CMI，中国联通回程走 CU/NTT/CMI 均衡，中国移动回程走 Level3。**适合面向中国内地用户的项目**，比如个人博客、小型电商、跨境业务双端兼顾。
- **精品BGP**（NVMe VPS 专属）：三网回程都走 CU 或 CMI 直连，**是国内方向优化最彻底的线路**，价格也最贵。适合对国内访问速度有强需求的业务。
- **国际BGP**（NVMe VPS 专属）：不含 CMI、CU，纯国际线路择优选路，**国内方向延迟较高**，适合面向东南亚、欧美等纯海外用户的跨境电商独立站、海外SaaS等。

一个很多人会问的关键问题——**买完之后能不能切换线路类型？** 答案是可以，但需要重新分配网络 IP 地址，并支付一次性服务费 50 元。所以与其事后切换，不如一开始就根据业务受众挑对线路。
